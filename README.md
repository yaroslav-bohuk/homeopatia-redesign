# Homeopatia redesign

Responsive static landing page in Ukrainian. No build or runtime dependencies.

## Preview

```sh
cd /workspace/homeopatia-redesign
python3 -m http.server 8080 --bind 0.0.0.0
```

## Configure contact

`VIBER_PHONE` in `script.js` is configured to the owner-provided +380673277076. Verify the chat opens on a device with Viber installed. Business details and consultation terms require owner review; the original website could not be accessed from this environment.

## GitHub Pages

Push these files to a new GitHub repository. In Settings → Pages select Deploy from a branch, `main`, `/ (root)`. No compilation is needed. Do not assume localhost is publicly accessible.

Illustration is original inline SVG. Fonts are self-hosted; their OFL licenses are included in fonts/. No third-party requests are required.
